温度 / 低温

植物冻害

Plant frost injury threshold

来源已核对·开放知识条目

植物冻害不是空气温度本身，而是叶面或细胞间隙结冰造成的组织损伤。轻霜常出现在 0 至 −2 ℃，硬冻约在 −2.2 ℃ 以下。这里取 271 K（约 −2.15 ℃）作代表值， 它位于轻霜与硬冻的交界附近；不同物种、部位和持续时间差异很大。

它是什么

植物冻害阈值指植物组织因低温受伤的温度，不是空气温度本身。霜冻发生在叶面或细胞间隙结冰；轻霜常在 0 至 −2 ℃ 出现，持续低温或更低温度会造成细胞膜损伤、叶片水浸状、褐变和萎蔫。[1] 这里取 271 K，约 −2.15 ℃，作为轻霜与硬冻交界附近的代表值。

怎样知道

农业推广资料把“霜”和“冻”分开：霜是叶面结冰，即使气温略高于冰点也可能发生；冻是植物内部降到 0 ℃ 以下并结冰。[1] 另一份园艺指南把 32 ℉ 以下定为冻警告，28 ℉ 以下定为硬冻，即约 −2.2 ℃。[2] 这些阈值来自田间观察和区域气候经验，不是实验室里对某一物种的精确测定。

数值与口径

271 K 等于约 −2.15 ℃。它描述敏感植物开始明显受害的低温段，不代表所有植物都在同一温度受伤。热带植物、开花中的果树和刚萌发的新叶更敏感；耐寒蔬菜和休眠枝条可承受更低的温度。[1] 受害程度还取决于降温速度、持续时间、风速和土壤湿度，突然降温比逐步适应更危险。

常见误解

第一，把气温当作叶面温度；晴朗无风的夜里，叶面可低于百叶箱气温。第二，认为 0 ℃ 以上绝不会结霜；局部表面仍可能降到冰点。第三，把一次霜冻等同于整株死亡；许多植物只是花芽或幼叶受损。第四，忽略持续时间；同样的 −2 ℃，持续数小时与短暂经过的后果不同。[2]

与其他温度的关系

271 K 略低于 lake-freezing 的 273.15 K，说明植物组织可以在淡水冰点附近或稍低时受害。它高于 freezer 的约 255 K，也高于 sea-ice 表面的 258 K 附近。与 water-freezing 相比，271 K 不是水的相变点，而是生物组织对低温的综合响应阈值。

适用条件与比较口径

  • 植物组织与叶面
  • 叶面、花芽与细胞间隙
  • 低温持续时间与降温速率
  • 田间受害观察与园艺指南

0 至 −2 ℃ 是轻霜与硬冻的常用分界；热带植物、开花中的果树和幼叶更敏感，耐寒品种可承受更低温度。 叶面温度可低于百叶箱气温，降温速度、持续时间、风速和土壤湿度都会改变受害程度。

水的冰点

标准大气压附近，冰与水的平衡温度约为 273.15 K（0 °C）。这是带条件的相变参考值；精密测温需要考虑压力、成分和溶解气体，而非把所有水的冻结过程视为完全相同。

温度 / 低温

冷冻室

家用冷冻室的安全储存目标是 0 °F（−18 ℃）或以下，本条取 −18 ℃（255 K）。 它是长期储存的目标空气温度，不是速冻温度，也不是食物中心的瞬时温度。

湖水结冰

淡水湖表层在标准大气压附近约 0 ℃ 开始结冰，即 273.15 K。这里描述的是与空气接触的 表层水，不是整个湖体的温度；溶解盐、有机物、水深和热收支都会改变实际结冰时间。

温度 / 低温

海冰表面

冬季北极海冰表面常降到 −15 ℃ 以下；卫星产品把低于 −15 ℃ 的区域单独标色。 这里取 258 K（约 −15.15 ℃）作代表值。它描述冰盖或雪盖最上层的温度， 既不是海水约 −1.8 ℃ 的冻结点，也不是整块冰的平均温度。

约 −15.15 ℃（258 K）↗

南极冬季最低温
