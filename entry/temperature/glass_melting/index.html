Corning 7740 玻璃工作点

Corning 7740 glass working point

来源已核对·开放知识条目

Corning 的 7740 硼硅酸盐玻璃资料表，将黏度 10⁴ poise 对应的工作点列为 1252°C，约 1525 K。本条采用明确牌号和黏度指标，避免把玻璃加工温度写成所有玻璃共同的熔点。

它是什么

这里讨论的不是某种“玻璃的统一熔点”，而是 Corning 7740 硼硅酸盐玻璃的工作点。玻璃在冷却时没有像晶体那样固定的熔化或凝固温度，而是从黏性液体逐渐变硬；工程上用某一黏度对应的温度来描述加工阶段。[2] 7740 是钠硼硅酸盐玻璃，常用于耐热器皿和实验室玻璃。

怎样测到

Corning 的材料属性表按黏度给出特性点：工作点对应 10⁴ poise，即 10³ Pa·s，温度为 1,252 °C；同表还列出软化点 820 °C（10⁷·⁶ poise）、退火点 560 °C（10¹³ poise）和应变点 510 °C（10¹⁴ poise）。[1] 这些数值来自厂家对牌号 7740 的标准化黏度测量，不是对某一块玻璃的相变观测，也没有给出该项的测量不确定度。

数值与口径

1,252 °C 换算为 1,525.15 K，展示取约 1,525 K。[1] 工作点描述玻璃可以成形、拉制或吹制的黏度区间，不等于“熔化炉温”，也不等于软化开始。软化点、退火点和应变点分别对应更高黏度、更低温的工艺阶段；把 1,525 K 当成所有玻璃的熔点会混淆材料与口径。[1][2] 不同配方、含水量和热历史的玻璃，同一黏度对应的温度也不同。

常见误解

第一，认为玻璃有一个像冰一样的固定熔点；玻璃是缺乏长程有序的固体，转变是连续的动力学过程。[2] 第二，把工作点当成“必须加热到的炉温”；实际炉温通常高于工作点，且取决于成形工艺。第三，把 Corning 7740 的数值套到钠钙玻璃、石英玻璃或光纤玻璃；它们的黏度曲线不同。第四，忽略黏度单位：10⁴ poise 等于 10³ Pa·s，不是 10⁴ Pa·s。

与其他温区的关系

1,525 K 低于纯硅熔点 1,687 K 和纯铁熔点 1,811 K，高于铝熔点 933.15 K。它低于炼钢出钢的约 1,893 K，与本生灯高温区的 1,773 K 同一量级，说明玻璃软化并不需要达到金属熔化的温度；这与黏度口径有关。[1]

本条的热力学温度单位与换算依据 BIPM 对开尔文的定义。[3]

深读一：量值口径

本条的核心量值是 1525.15 K，量的是Corning 7740玻璃在10⁴ poise黏度下的工作点。数值来自本条既有审阅链，不是按标题重新估算；标为近似值。[1] 口径一变，读数就会跟着变，因此正文始终把单位、参照物与条件写在一起。

条件记录为：厂家Corning Code 7740材料属性表；working point对应黏度10⁴ poise（10³ Pa·s）， 温度为1252°C。厂家未在表中给出该项测量不确定度，不视为所有玻璃的相变点或炉温设定。。这些条件决定它能否与另一条读数直接比较；例如把直径换成半径、把瞬时值换成年均值，都会改变量级判断，不能只看数字大小。[2]

深读二：误差与边界

放进尺度阶梯时，可对照铝熔点（933.473）。本条与它不是简单的倍数关系，而是同一量纲下不同口径的两个锚点；先统一单位与参照，再讨论谁大谁小。[3]

误差与边界：未单列数值不确定度，误差主要来自口径选择与样本/模型假设。若要做跨条目比较，应保留原始有效数字，不把换算结果补到仪器并不支持的精度；本条的文字解释与图景说明只用于建立尺度感，不替代测量记录。[1][2]

补充：怎样复核这条读数

复核时先把 1525.15 K 还原到条目写明的参照与条件，再做单位换算；与相邻条目比较时，只比较同一口径下的量值，不把标题里的四舍五入值当成新测量。若换算后落在两个已知锚点之间，应同时报告两个锚点与所用倍率，方便读者复算。[1][2] 本条不新增独立测量，也不改变原有来源与引用编号。

适用条件与比较口径

  • 厂家Corning Code 7740材料属性表；working point对应黏度10⁴ poise（10³ Pa·s）， 温度为1252°C。厂家未在表中给出该项测量不确定度，不视为所有玻璃的相变点或炉温设定。

Corning 表值给出 1252°C，未附该项测量不确定度；配方、含水量、热历史和黏度测量方法都会使同一黏度对应温度略有偏移。
