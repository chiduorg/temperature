湖水结冰

Freshwater lake surface freezing point

来源已核对·开放知识条目

淡水湖表层在标准大气压附近约 0 ℃ 开始结冰，即 273.15 K。这里描述的是与空气接触的 表层水，不是整个湖体的温度；溶解盐、有机物、水深和热收支都会改变实际结冰时间。

它是什么

湖水结冰通常指淡水湖表层开始形成稳定冰盖的温度。标准大气压下，纯水在 0 ℃ 结冰，即 273.15 K；[1] 但湖水含有溶解盐和有机物，实际表层冰点会略低。这里取 273.15 K，作为淡水表层的参考值，不是整个湖体的温度。

怎样知道

NSIDC 的冰圈资料把淡水的冻结点写作 0 ℃，并对比海水约 −1.8 ℃ 的冻结点，说明盐度会降低冰点。[1] Britannica 也指出，低于 0 ℃ 时液态水形成河冰、海冰和湖冰。[2] 湖面是否结冰，还要看热收支：气温、风速、太阳辐射、水深和湖底储热共同决定表层何时失去热量。

数值与口径

273.15 K 等于 0 ℃。它适用于与空气接触、盐度很低的表层水；深水湖的底部在整个冬季可能仍保持约 4 ℃。湖面结冰后，冰层厚度增加的速度由冰面散热和冰下热流控制，而不是单纯由气温决定。溶解盐、波浪和人为搅动都会改变局部结冰时间。[1]

常见误解

第一，认为整个湖水同时降到 0 ℃；实际是表层先结冰。第二，把气温 0 ℃ 当成湖水立刻结冰；水有热容量，需要持续散热。第三，把海水和淡水的冰点混用；海水约 −1.8 ℃。[1] 第四，认为冰盖越厚气温一定越低；厚度还取决于冻结持续时间和雪盖保温。第五，忽略湖底储热；深水湖的底层冷却远慢于表层。[2]

与其他温度的关系

273.15 K 与 water-freezing 的参考值相同，但这里强调湖面这一位置。它高于 plant-frost 的 271 K，低于 sea-ice 表面的 258 K。与 deep-ocean 的接近 277 K 相比，湖面在冬季可以更冷，而湖底仍较暖，说明同一个水体内部存在明显温度分层。

适用条件与比较口径

  • 淡水
  • 湖面表层
  • 持续散热至表层达到冰点
  • 标准大气压下的冰水平衡参考

273.15 K 是纯淡水在标准大气压附近的冰点参考；湖水含溶解盐和有机物，实际表层冰点会略低。 湖面是否结冰还取决于气温、风速、太阳辐射、水深、湖底储热和雪盖，而不是单一温度值。

温度 / 常温

水的冰点

标准大气压附近，冰与水的平衡温度约为 273.15 K（0 °C）。这是带条件的相变参考值；精密测温需要考虑压力、成分和溶解气体，而非把所有水的冻结过程视为完全相同。

约 273.15 K（0 °C）↗
温度 / 低温

海冰表面

冬季北极海冰表面常降到 −15 ℃ 以下；卫星产品把低于 −15 ℃ 的区域单独标色。 这里取 258 K（约 −15.15 ℃）作代表值。它描述冰盖或雪盖最上层的温度， 既不是海水约 −1.8 ℃ 的冻结点，也不是整块冰的平均温度。

约 −15.15 ℃（258 K）↗
温度 / 低温

植物冻害

植物冻害不是空气温度本身，而是叶面或细胞间隙结冰造成的组织损伤。轻霜常出现在 0 至 −2 ℃，硬冻约在 −2.2 ℃ 以下。这里取 271 K（约 −2.15 ℃）作代表值， 它位于轻霜与硬冻的交界附近；不同物种、部位和持续时间差异很大。

约 −2.15 ℃（271 K）↗
温度 / 低温

多年冻土

多年冻土地温在连续冻土带常见 −5 至 −15 ℃，本条取 −10 ℃（263 K）。 它指地下土壤或岩石的温度，不是地表气温；0 ℃ 是冻土存在的温度上限。

约 −10 ℃（263 K）↗
温度 / 低温

深海温度

2000 米以下的深层海水通常约 2–4 ℃，本条取 275 K（约 2 ℃）。 它是深层水团的温度，不是海表温度，也不是热液喷口的局部高温流体。
