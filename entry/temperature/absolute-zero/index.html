绝对零度

Absolute zero

来源已核对·开放知识条目

绝对零度是热力学温标的零点：0 K 等于 −273.15 °C。温度降到零不等于一切微观运动消失；量子零点运动不能用经典粒子的完全静止来表示。

温标从哪里开始

绝对零度是热力学温标的零点。0 K 与 −273.15°C 表示同一个温度，而摄氏零度仍是 273.15 K。开尔文不加“度”字；温差 1 K 与温差 1°C 一样大，区别在于两种温标选择了不同的零点。[1]

低温不等于微观世界静止

把冷却想成所有粒子逐渐停下，是经典图像。量子理论允许物质在零温时仍有零点运动，它不属于由热驱动的运动。因此，画面中的粒子动画停住，只能表达一种展示状态，不能证明位置、动量和量子涨落都变成零。[1]

实验怎样建立温度读数

现实测温需要把仪器读数与可复现的物理性质联系起来。现代开尔文通过固定玻尔兹曼常数定义；实验室仍可利用水三相点等条件校准温度计。零点的定义不要求先制造一份真正处于 0 K 的样品，再拿它校准全部仪器。热力学第三定律进一步表明，0 K 只能无限逼近，不能以有限步骤达到。[2]

能量尺度与冷却尺度

玻尔兹曼常数把温度和微观能量尺度联系起来，而大量粒子的运动需要用统计分布描述。同一温度不意味着每个粒子具有相同速度，也不意味着不同大小的物体拥有相同总能量。比较接近零点的实验，还要说明测量的是哪一部分物质及其状态。[3]

例如讨论“降到原来一半”时，必须先选定绝对温标；从 20°C 降到 10°C，并不等于热力学温度减半。这个简单换算说明：尺度图中的零点关系，比把所有冷却想成同一种颜色逐渐变暗更有信息。[1]

在尺度图上怎样理解零

从液氮到更低温体系，读数可以不断靠近温标起点；图中的 0 K 却是定义位置，不是实验纪录。这里保留这个精确零点，以便理解其他温度距离它有多远；装置外观和运动均为概念示意。

这个数值的误差账本

绝对零度是 0 K，即 −273.15 ℃，是热力学温度的理论下限。它不能被有限步骤达到，只能无限接近；宇宙微波背景约 2.725 K，是当前宇宙的低温背景，不是绝对零度。把 0 K 写成“没有能量”不准确：量子零点能仍然存在。

换一个尺度看它

0 K 与室温 293 K 相差 293 K；与太阳表面 5772 K 相比，室温更接近绝对零度而不是太阳。液氦在 4.2 K 以下进入超流态，超导体在临界温度以下出现零电阻。绝对零度不是一个可到达的房间，而是一条渐近线。

0 K 是渐近线，不是可到达的房间

热力学第三定律指出，有限步骤无法把系统冷却到绝对零度；每降低一点温度，需要移走的热量越来越多。[1][2] 实验室能达到的最低温度以皮开尔文、纳开尔文计，却仍不是 0 K。把 0 K 画成温度计底端的一条实线，只是坐标约定。

五轴对照

在温度轴，0 K 是定义零点；在空间轴，低温实验装置把样品与外界隔绝；在时间轴，宇宙微波背景约 2.7 K，是当前宇宙的低温背景；在质量轴，氦-4 原子核的零点能说明 0 K 仍有量子运动。零点、背景温度与量子基态不是同一个概念。[1][3]

负温度不是比 0 K 更冷

粒子数反转的系统可以出现“负温度”，但它的能量高于正无穷温度，仍比 0 K 热得多。负温度只在特定孤立量子系统的统计描述中出现，不是把冰箱再调低一度。把负温度画在 0 K 左边，会误解温标的顺序。[1][S1]
