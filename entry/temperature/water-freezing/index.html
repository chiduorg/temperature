水的冰点

Ice–water equilibrium

来源已核对·开放知识条目

标准大气压附近，冰与水的平衡温度约为 273.15 K（0 °C）。这是带条件的相变参考值；精密测温需要考虑压力、成分和溶解气体，而非把所有水的冻结过程视为完全相同。

冰点描述的是一种平衡条件

日常把0 °C称作水的冰点，是一个很有用的近似参照。这里讨论的是冰、液态水与空气达到相应平衡时的温度，不是任何一杯水在任何环境中都会以同样速度、同一读数开始结冰。NIST的研究把压力和水中溶解的大气气体一并纳入了分析。[1]

为什么写“约273.15 K”

所引研究在标准大气压及其模型条件下，给出的冰点约为273.15002 K。本页为日常尺度取约273.15 K，并不使用论文中的更多小数位来暗示容器和温度计也有同样精度。研究还比较了不同海拔和气压下的测量，说明精密结果必须连同环境条件来读。[1]

温标换算的准确，与相变参考的近似

摄氏温度与开尔文温度的数值相差273.15，这是温标换算中的定义关系；温度升高1 °C与升高1 K表示相同的温差。所以0 °C对应273.15 K，而不是整数273 K。换算关系的准确，并不会把真实样品在给定条件下的相变温度也变成不带条件的自然常数。[2]

冰点与三相点不能混用

冰点实验中与空气接触的冰水体系，与用于精密测温的水三相点体系有不同的压力和气体条件。NIST论文正是通过二者的温度差来检验模型；论文讨论的压力效应和溶解空气效应都要计入。因此不能只因为两个数字很接近，就把0 °C、三相点和任意水样的冻结读数视为同一件事。[1]

怎样理解这里的画面

冰块、水面和容器表示固态与液态的联系，并没有计算结晶速率或容器内每一点的温度场。温度尺上的参考点回答“采用哪种相变条件”，动画快慢不回答“一杯水需要多久才能冻住”。继续阅读水的沸点，可以比较同一种物质在另一组压力与物态条件下的参考温度。[1]

这个数值的误差账本

水的冰点 273.15 K（0 ℃）是在标准大气压下的定义点；压力、溶解物与过冷都会改变实际结冰温度。海水冰点约 −2 ℃，高盐卤水更低；纯净水在无扰动条件下可过冷到 0 ℃以下仍不结冰。0 ℃不是所有水同时结冰的温度。

换一个尺度看它

0 ℃等于 273.15 K，比绝对零度高 273.15 K，约为室温的 93%。它与人体核心温度 37 ℃相差 37 K；与太阳表面 5772 K相比，水的液态窗口很窄。地球生命的很多反应都发生在 0–100 ℃之间，但这不是宇宙中水的唯一状态。

过冷与成核

纯净水在无扰动、无尘埃的条件下可以冷却到 0 ℃以下仍保持液态，这叫过冷。[1] 结冰需要成核位点，容器壁、杂质或气泡会降低成核能垒。看到“低于 0 ℃还没结冰”不说明冰点错了，只说明相变需要动力学条件。

溶解物会降低冰点

海水、盐水和含糖溶液的冰点低于 0 ℃；溶质降低水的气相化学势，需要更低温度才能与冰平衡。[1][2] 道路撒盐融冰利用的正是这个效应。冰点不是纯水的唯一定值，必须说明样品成分与压力。

五轴对照

在温度轴，纯水冰点约 273.15 K；在空间轴，冰晶与水面是不同相；在质量轴，水分子质量约 2.99×10⁻²⁶ 千克；在时间轴，结冰快慢取决于成核与散热。温度、成分与时间共同决定是否结冰。[1][2]

水的沸点

在标准大气压附近，水约在 100 °C（373.15 K）沸腾。沸点随压力变化：较低压力下会在较低温度沸腾，较高压力下则需要更高温度。

水三相点

水的三相点在 ITS-90 中赋值为 273.16 K，即 0.01 °C，对应压力 611.657 Pa。它是冰、液态水与水蒸气共存的参考状态；自 2019 年起，开尔文已改由玻尔兹曼常数定义。
